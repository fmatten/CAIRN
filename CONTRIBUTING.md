# Contributing to CAIRN

Thank you for your interest in contributing.

CAIRN uses a dual-license model:

- EUPL-1.2, and
- commercial licensing by Iscad GmbH.

By contributing, you confirm that you have the right to submit the contribution and that your contribution may be distributed by Iscad GmbH under both the EUPL-1.2 and a commercial Iscad GmbH license.

## Required sign-off

Each commit should include a Developer Certificate of Origin sign-off:

```text
Signed-off-by: Your Name <your.email@example.org>
```

Use:

```bash
git commit -s
```

## Do not submit

Please do not submit:

- code you do not have the right to contribute,
- third-party code without clear license information,
- patient data or personal data,
- secrets, passwords, API tokens or credentials,
- regulated medical-device claims without prior review by Iscad GmbH.

## License headers

Recommended source file header:

```text
SPDX-FileCopyrightText: 2026 Iscad GmbH
SPDX-License-Identifier: EUPL-1.2 OR LicenseRef-Iscad-Commercial
```
