# Developer Certificate of Origin

This project uses a Developer Certificate of Origin style sign-off.

By adding a `Signed-off-by` line to a commit message, the contributor certifies that they have the right to submit the contribution and that it may be distributed under the project's licensing terms.

Example:

```text
Signed-off-by: Jane Doe <jane@example.org>
```

Use:

```bash
git commit -s
```
